Career Copilot

A full-stack AI job application assistant that turns resume tailoring and cover letter writing into a more structured workflow.

Problem

Students often apply to many roles at once, and each job posting emphasizes different skills. Rewriting application materials for every role is time-consuming, and generic AI tools can easily drift into advice that sounds polished but is not grounded in the student's real experience.

What I Built

I built a dashboard where users can upload a resume, save job postings, compare the two, and generate resume bullets or cover letters from that saved context.

  • Resume upload flow
  • Saved job posting management
  • Resume-to-job match analysis
  • AI-assisted resume bullet rewriting
  • Cover letter generation
  • Authenticated dashboard for saved application materials

My Role

I worked across the full stack, including frontend flows, database models, authentication, saved user data, prompt structure, and deployment.

Tech Stack

Next.js, React, TypeScript, Prisma, Supabase Postgres, Clerk, Google Gemini, AI SDK, Tailwind CSS, and Vercel.

Challenge

The main design challenge was keeping AI output useful without inventing qualifications. I wanted the product to help users frame their real experience better, not fabricate new experience.

What I Learned

This project taught me that useful AI products need structure around the model. The prompts matter, but so do the user flow, database context, authentication, and product constraints around the AI.
